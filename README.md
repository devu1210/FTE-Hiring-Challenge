# ReLu Consultancy — Data Extraction Engineering Challenge

A collection of Python-based data extraction, web scraping, data processing, and automation solutions developed for the **ReLu Consultancy FTE Hiring Challenge — Data Extraction Engineering**.

The project focuses on extracting data from real-world websites, handling dynamic content and pagination, cleaning and validating extracted information, transforming unstructured web data into structured datasets, and building a simple web interface for exploring the processed data.

---

## Overview

The challenge evaluated practical skills in:

- Web scraping and data extraction
- Python automation
- Dynamic web page handling
- API-based data extraction
- Pagination and navigation
- Data parsing and cleaning
- Data validation
- Structured CSV generation
- Data analysis
- Flask web application development
- REST API development
- Problem solving and attention to detail

The repository contains two primary extraction challenges and an additional bonus data explorer application.
